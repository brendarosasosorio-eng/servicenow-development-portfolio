# GlideAjax Examples

ServiceNow JavaScript examples demonstrating asynchronous communication between client-side scripts and server-side Script Includes using GlideAjax.

## Examples

- Retrieve user information
- Retrieve an Assignment Group manager
- Retrieve location information
- Retrieve an employee number
- Dynamically populate form options

## Concepts Demonstrated

- Client Scripts
- GlideAjax
- Client-callable Script Includes
- AbstractAjaxProcessor
- GlideRecord
- JSON responses
- Asynchronous callbacks
- g_form

All examples have been anonymized and recreated for portfolio and demonstration purposes.
